## Coordinator retirement and debt settlement

The Lasna system reserve is **zero** and debt is **`3871900000000000` wei (0.0038719 REACT)** at block `9229619`; the coordinator's own native balance is zero. This debt belongs to the Lasna system account, not the Base executor fee credit or Base callback proxy. Two system deposits totaled 0.5 REACT. At completion block `9227202`, the system still held `124979300000000000` wei reserve and zero debt. It kept receiving billable idle Cron100 reactions while its eight subscriptions remained installed. At block `9228100` reserve was `10444900000000000` wei; the [last charged Cron reaction](https://lasna-omni.reactscan.net/tx/0x57c96d087dd75d32543d196a3734adb40c6432f37707f636af27d46b1d94f81d) in block `9228101` (15:47:12 UTC) succeeded, referenced native Cron block `9228100` log `2`, and emitted system debt and reserve-exhaustion logs. Reserve became zero and debt `3871900000000000` wei. The observed increase in required funds across that reaction is `14316800000000000` wei; receipts do not itemize the gas bill, so it is an accounting delta. `lastCronBlock=9228100` through the observation head. The source can continue emitting ticks even when the depleted coordinator no longer receives them.

Continuous idle Cron100 execution consumes testnet funds, so the demonstration coordinator was retired. The owner called `shutdownPermanently()` in [Lasna transaction `0xb20f…8cba`](https://lasna-omni.reactscan.net/tx/0xb20f065c4a9f03163be9ae2fe7337461e08e037728666cb264909cd218a78cba), block **9230858**. Its receipt has `status=1`, eight system unsubscribe logs at indices `1–8` (including native Cron100 at index `2`), and the coordinator's `Shutdown` event at index `9`. The transaction sender is the coordinator owner, the recipient is the coordinator, and the input selector matches `shutdownPermanently()`.

The owner then sent **`3871900000000000` wei (0.0038719 REACT)** to the Lasna system contract for this coordinator in [settlement transaction `0x99ba…ae8b`](https://lasna-omni.reactscan.net/tx/0x99ba6821cc5f05b1ea0f27fa91c2271ba1924e95ec42067512a7395b20f1ae8b), block **9231000**. Its receipt has `status=1` and a system log indexed by the coordinator. The transaction value equals the previously observed debt. Independent read-only calls after settlement return coordinator `shutdown=true` and system `debt(coordinator)=0`, `reserves(coordinator)=0`.

Shutdown is permanent. This retired coordinator cannot perform new autonomous recoveries. Any new autonomous recovery deployment requires a fresh coordinator and corresponding executor deployment, with new subscriptions and funding. The completed Base policy and employee's refundable fee credit are separate from the Lasna system debt settlement.
