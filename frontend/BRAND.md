# RECLAIM identity

Direction: dark infrastructure editorial. The visual system uses #080808, #101010, #161616, #252525, #FAFAFA, #A1A1AA and selective #FF4545. Geist Sans carries hierarchy; Geist Mono identifies chain state and evidence.

Three original symbol explorations are in `public/brand/`:

- `concept-orbit.svg`: circular return motion. Legible, but too close to a generic recycling symbol.
- `concept-fold.svg`: a folded path inside an elongated frame. Strong direction but visually crowded at small sizes.
- `concept-return.svg`: selected. The asset path returns through a square frame to a fixed interior point. It stays distinct in monochrome and at favicon scale.

The final mark tightens the square return path around a small fixed point. The same geometry is used in the red and monochrome SVG marks, navigation mark, wordmark and favicon. It was visually checked at 16, 24, 48 and 160 pixels. `hero-network.svg` extends that geometry into a Base → Reactive → recipient route with restrained red lighting; its motion is explicitly illustrative.

Final assets: `logo.svg`, `logo-mono.svg`, `wordmark.svg`, `hero-network.svg`, `social.svg`, rendered 1200 × 630 `social.png`, and `app/icon.svg`. The earlier concept explorations and generated QA screenshots are excluded from the eventual Git add by `.gitignore`.
